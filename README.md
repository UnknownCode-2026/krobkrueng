# ครบเครื่อง — KrobKrueng V1

เว็บรวมเครื่องมือออนไลน์ภาษาไทย พัฒนาด้วย Next.js + TypeScript และ deploy บน Vercel

## V1
- Gold Theme + Light/Dark mode
- Mobile-first responsive
- Catalog 58 เครื่องมือ
- เครื่องมือคำนวณหลักใช้งานได้จริง
- PromptPay QR / QR Code
- Resize / Compress / Convert image ใน browser
- Search + category filter
- Dynamic tool/category pages
- SEO sitemap + robots
- โมดูล PDF และบางเครื่องมือขั้นสูงติดป้าย BETA จนกว่าจะพร้อมจริง

Production: https://krobkrueng.vercel.app
