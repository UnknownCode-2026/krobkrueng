# ครบเครื่อง — Krobkrueng

เว็บไซต์เครื่องมือออนไลน์ฟรีสำหรับช่วยเรื่องเล็ก ๆ ในชีวิตประจำวัน

## V1.7 — Complete Home Tools & Tool Engine V2

V1.7 ทำให้เครื่องมือหลักบนหน้า Home ใช้งานจริงครบ 8/8 ตัว พร้อมอัปเกรดระบบกลางของหน้าเครื่องมือให้รองรับ Preset, แชร์ผลลัพธ์, ประวัติ Local History, Related Tools และข้อมูลเครื่องมือจาก Registry กลาง

### เครื่องมือที่ใช้งานจริงครบ 8 ตัว

- `/tools/split-bill` — หารค่าใช้จ่าย
- `/tools/discount` — คำนวณส่วนลด
- `/tools/what-to-eat` — วันนี้กินอะไรดี
- `/tools/leave-time` — ควรออกกี่โมง
- `/tools/date-count` — นับวัน
- `/tools/salary` — แบ่งเงินเดือน
- `/tools/compare-value` — เทียบความคุ้มค่า
- `/tools/percentage` — คำนวณเปอร์เซ็นต์

### Tool Engine V2

- เพิ่ม Registry กลางที่ `data/homeTools.ts` เป็น Single Source of Truth สำหรับ 8 เครื่องมือหลัก
- หน้า Home, Search, Recent, Favorites และ Tool Page ใช้ข้อมูลชุดเดียวกัน
- Recent Tools ขยายเป็นสูงสุด 6 รายการ
- Favorites ใช้ Local Storage ชุดเดียวกันระหว่าง Home และ Tool Page
- เพิ่ม Web Share API พร้อม fallback เป็นการคัดลอกผลลัพธ์
- เพิ่ม Preset / Quick Input สำหรับเครื่องมือที่เหมาะสม
- เพิ่ม Local Result History สูงสุด 5 รายการต่อเครื่องมือ พร้อมปุ่มล้างประวัติ
- Related Tools ใช้ความเกี่ยวข้องของเครื่องมือแทนการสุ่ม
- คง Soft 3D Icon System, Light/Dark Mode และ Mobile-first UI จาก V1.5–V1.6
- ใช้ CSS Module ของ Tool Page เพื่อป้องกัน Style ชนกับหน้า Home

### หารค่าใช้จ่าย

- รองรับยอดรวม
- จำนวนคน
- Service Charge
- VAT
- ทิป
- ตัวเลือกปัดยอดต่อคนขึ้นเป็นบาทถัดไป
- Preset จำนวนคน 2–6 คน
- สรุปยอดรวมและยอดต่อคน
- คัดลอก/แชร์ผลได้

### คำนวณส่วนลด

- ราคาเดิม + เปอร์เซ็นต์ส่วนลด
- Preset 10 / 20 / 25 / 30 / 50%
- ราคาหลังลด
- จำนวนเงินที่ประหยัด
- Validation 0–100%

### วันนี้กินอะไรดี

- เลือกประเภทอาหาร
- เลือกงบประมาณ
- เลือกเผ็ด/ไม่เผ็ด
- สุ่มจากชุดเมนูที่ตรงเงื่อนไข
- สุ่มใหม่ได้ทันที
- แชร์ชื่อเมนูได้

### ควรออกกี่โมง

- เวลาที่ต้องถึง
- เวลาเดินทาง
- เวลาสำรอง
- Preset เวลาสำรอง 10 / 15 / 30 / 45 นาที
- รองรับกรณีต้องออกตั้งแต่วันก่อนหน้า

### นับวัน

- วันที่เริ่มต้น / สิ้นสุด
- จำนวนวันทั้งหมด
- สรุปเป็นสัปดาห์ + วัน
- แสดงชื่อวันของวันที่สิ้นสุด
- Validation วันที่ย้อนลำดับ

### แบ่งเงินเดือน

- เงินเดือนสุทธิ
- ค่าใช้จ่ายจำเป็น / ใช้ส่วนตัว / ออม
- Preset 50/30/20, 60/20/20, 70/20/10
- ตรวจสอบสัดส่วนรวมต้องเท่ากับ 100%
- สรุปยอดเงินจริงของแต่ละส่วน

### เทียบความคุ้มค่า

- เปรียบเทียบสินค้า A / B
- ราคาและปริมาณ
- รองรับ ชิ้น / กรัม / กก. / มล. / ลิตร
- แปลงหน่วยในกลุ่มเดียวกันก่อนเปรียบเทียบ
- แสดงราคาต่อหน่วยและเปอร์เซ็นต์ความต่าง

### คำนวณเปอร์เซ็นต์

รองรับ 3 รูปแบบ:
- หา X% ของจำนวน
- หาค่าว่าคิดเป็นกี่ % ของอีกจำนวน
- หาเปอร์เซ็นต์การเพิ่มหรือลด

### Privacy

- อัปเดตหน้า `/privacy` ให้ระบุ Favorites, Theme, Recent Tools และ Local Tool History
- ประวัติผลลัพธ์เก็บใน Browser เท่านั้น
- ผู้ใช้ล้างประวัติรายเครื่องมือได้

ยังไม่มี Login, Database, Admin, Payment หรือ Cloud Account ใน V1.7
